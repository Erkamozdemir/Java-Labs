# Java Labs

A collection of lab work completed throughout my Java learning journey — from core language fundamentals to GUI development and data structures. Each lab targets a specific concept and builds on the previous ones.

---

## What I Worked On

### Core Java

Variables, data types, operators, control flow (`if/else`, `switch`), and loops (`for`, `while`, `do-while`). The foundation everything else builds on.

### Object-Oriented Programming

Classes and objects, constructors, encapsulation with private fields and getters/setters, inheritance with `extends` and `super`, method overriding, and access modifiers. This is where the shift from writing procedures to designing systems happens.

### Advanced OOP

Abstract classes, interfaces, polymorphism, upcasting and downcasting, `instanceof` checks, and runtime type resolution. Also covers how to design proper class hierarchies and define behavioral contracts through interfaces.

### Exception Handling

`try-catch-finally` and `try-with-resources` blocks, checked vs unchecked exceptions, propagation with `throws`, and writing custom exception classes. The goal here was learning how to handle failure gracefully rather than crashing.

### Data Structures

Implementing and working with core data structures in Java — arrays, linked lists, stacks, queues, and trees. Both manual implementations from scratch and usage of Java's built-in Collections framework (`ArrayList`, `LinkedList`, `HashMap`, `Stack`).

### GUI (Graphical User Interface)

Building desktop applications with Java Swing. Window creation, layout managers, event listeners, buttons, forms, and connecting UI components to application logic.

### AUI (Advanced User Interface)

More sophisticated UI patterns on top of Swing — custom components, dialogs, menus, and structuring larger GUI applications cleanly.

---

## Skills Gained

By the end of this series I can confidently:

- Apply all four OOP principles (encapsulation, inheritance, abstraction, polymorphism) in real code
- Design class hierarchies and write interface contracts from scratch
- Implement fundamental data structures both manually and using Collections
- Build functional desktop GUI applications with Java Swing
- Handle exceptions properly and propagate errors across layers
